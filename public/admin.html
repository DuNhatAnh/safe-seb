Quy tac dinh dang cau hoi

1. Dinh dang JSON (Moi cau 2-6 phuong an, dung 1 dap an is_correct: true) 
[
  {
    "question": "Thu do cua Viet Nam la gi?",
    "options": [
      { "text": "Ha Noi", "is_correct": true },
      { "text": "Hue", "is_correct": false },
      { "text": "Da Nang", "is_correct": false },
      { "text": "TP.HCM", "is_correct": false }
    ]
  }
]
2. Dinh dang PDF (Xuat tu Word/Docs, khong phai ban scan) 
Cau 1: Thu do cua Viet Nam la gi?
*A. Ha Noi
B. Hue
C. Da Nang
D. TP.HCM

Cau 2: 2 + 3 = ?
A. 4
B. 5
C. 6
D. 7
Dap an: B
Cac luu y quan trong khi soan de:
  • Bat dau cau hoi bang Cau N:, Bai N: hoac N. di lien dau cham/ngoac roi cach ra.
  • Cac phuong an bat dau bang chu hoa A., B., C., D. o dau dong.
  • Dap an dung duoc danh dau bang dau * truoc chu cai (vi du *A.), chu khoanh tron Ⓔ-Ⓗ, hoac dong Dap an: X o cuoi cau.
  • Noi dung cau hoi hoac phuong an dai co the xuong dong, he thong se tu dong ghep noi.
